## Требуется для ввода в эксплуатацию

[Инструкция запуска](ORDER-SERVICE.md) и шаблоны `deploy/` подготовлены. Необходимо выбрать хостинг и место хранения, запустить один Node24 процесс на постоянном диске, настроить TLS reverse proxy и ClamAV, SMTP/отправителя, защищённые секреты, резервные копии и внешние оповещения. Установить PUBLIC_ORDER_API_URL в GitHub repository variables; проверить доставку/вложение на согласованном реальном заказе, SPF/DKIM/DMARC. Согласовать политику с фактическими поставщиками и сроками.

GitHub Pages не выполняет API и не задаёт произвольные security headers. CSP meta уже входит в сборку; заголовки самого публичного сайта, HSTS и защита от embedding требуют настройки CDN/proxy/хостинга и внешней проверки. Нельзя считать их автоматически изменёнными этим commit. Из этой среды публичный домен ранее блокировался исходящим прокси.
